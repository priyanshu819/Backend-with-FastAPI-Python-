🚀 FastAPI Backend Project

A modern backend built with **FastAPI** ⚡ — designed for speed, scalability, and simplicity.  
This repo demonstrates clean architecture, async APIs, and integration with databases.

---
📌 Features
- ⚡ High-performance APIs with FastAPI
- 🔒 Authentication & Authorization (JWT/OAuth2)
- 🗄️ Database integration (SQLAlchemy / PostgreSQL / SQLite)
- 📝 Pydantic models for validation
- 🌐 CORS enabled for frontend communication
- 🧪 Unit tests with Pytest
